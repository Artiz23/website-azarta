# Azarta

Сайт-визитка и портфолио студии **Azarta**: разработка сайтов и Telegram-ботов.

## Стек

- React + TypeScript + Vite
- GSAP (ScrollTrigger) + Lenis (smooth scroll)
- Кастомный курсор, reveal-анимации, форма заявки

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```
